# Security policy

Please report suspected vulnerabilities through [GitHub private vulnerability
reporting](https://github.com/heyo-sh/heyo-status/security/advisories/new).
Do not publish exploit details, credentials or monitor URLs in a public issue.
Include the affected version, deployment target, steps to reproduce and impact.

We investigate reports privately and coordinate a fix and disclosure with the
reporter. Keep `@heyo-sh/heyo-status` and the generated project's framework and
deployment dependencies updated; see the [release checklist](RELEASING.md)
for the security audit and Vercel dependency overrides.
